# Visual Maps

The visual tools turn internal-link data into something you can inspect without reading row after row of URLs.

DMA InternLink Mapper includes several views because no single graph answers every question well.

## Link Map

Use the Link Map when you want to focus on how one page connects to others.

It is useful for checking:

- Incoming links
- Outgoing links
- Redirected targets
- Broken relationships
- Pages that appear unusually isolated or unusually connected

## Page Architecture

Page Architecture helps you inspect the structure around an individual page in more detail.

Use it when you are reviewing an important landing page, guide, product page or other content that should have clear supporting links.

## Site Architecture

Site Architecture gives you a broader structural view.

It is useful for spotting clusters, isolated sections and areas where the site architecture may not match the way you intended people to navigate.

## Knowledge Graph

The Knowledge Graph provides a more exploratory view of the latest completed scan.

You can inspect relationships between pages, choose graph depth and density, and use the selected-page panel to review signals for a specific node.

The graph is read-only. Exploring it does not modify posts, links or settings.

## 2D and 3D views

Where the interface provides both views, use 2D for quick analysis and 3D when the extra depth genuinely helps you understand a dense structure.

A prettier graph is not automatically a more useful graph. SEO has enough decorative dashboards already.

## Large sites

Visualizations use practical display limits to stay responsive.

If a site contains a very large number of pages or relationships, use search, graph depth and density controls to narrow the view instead of trying to display the entire web at once.

## Exporting

The plugin can provide local report and visual export options depending on the current view, including CSV, PDF or image-based outputs where supported.

Exports are useful for audits, handoff notes and comparing architecture over time.
