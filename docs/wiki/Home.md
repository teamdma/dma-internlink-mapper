# DMA InternLink Mapper Wiki

DMA InternLink Mapper is a WordPress plugin for understanding how pages on a site connect to each other.

It is built for site owners, developers and SEO teams who want to inspect internal links without sending site content to a remote AI or analytics service. You run a scan when you need one, then use the reports and visual maps to find orphan pages, weak anchors, broken links, redirects and useful internal-link opportunities.

The plugin does not promise rankings. Its SEO score is a local diagnostic signal designed to help you spot structural problems and review pages more consistently.

## What you can do

- Review incoming and outgoing internal links.
- Find orphan pages and weak anchor text.
- Discover internal-link opportunities from existing content.
- Preview and review link insertions before changing content.
- Inspect broken links and redirects.
- Create reviewed 301 or 302 redirects with loop protection.
- Explore the site through Visual Map, Page Architecture, Site Architecture and Knowledge Graph views.
- Run on-page SEO checks.
- Import Google Search Console CSV or ZIP exports locally.
- Work with Gutenberg, Classic Editor and supported Elementor text controls.

## Requirements

DMA InternLink Mapper requires WordPress 6.5 or newer and PHP 7.4 or newer.

Safe HTML analysis and verified link insertion also require the PHP DOM/XML extension.
