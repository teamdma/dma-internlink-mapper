# Contributing

Keep changes small enough to review and test.

Before opening a pull request:

1. Run the PHP lint and security invariant checks.
2. Run the unit tests.
3. Run the security and PHP compatibility PHPCS rulesets.
4. Test the affected WordPress admin flow manually.
5. Do not combine large formatting rewrites with functional changes.

Security, data integrity and backward compatibility take priority over cosmetic refactors.
